# 窗口、提交与后台流程验收

日期：2026-09-12。此记录补充最初的开发预览验收。

已实现：拖动位置跨启动恢复、显示器不可用时回退可见区域；Enter / ⌘Enter 提交选择、Shift Enter 换行；可选提交后自动收起；可选跳过添加前确认；自定义全天提醒日期和小时/分钟；后台失败的原生弹窗与菜单栏状态。

默认值保持原操作习惯：⌘Enter 提交、添加前确认开启、提交后自动收起关闭。Esc 和呼出快捷键只收起，不提交。所有新增设置均兼容旧配置，既有服务商和日历选择不会因新增字段被重置。

## 行为边界

- 不轮询模型，不自动重试失败请求，不因收起窗口重复提交。
- 后台指应用仍在运行；退出应用会中断生成，不会在重启后自动重新发送。
- 自动添加仅处理整批完整、无需补充/确认假设/确认冲突的日程。无法自动处理时保留草稿并主动提示。
- 请求失败、写入异常、部分写入或读回无法确认都会进入提示路径；不把未知结果当成失败后自动再创建。
- 全天提醒以事件时区计算，范围为当天至提前 7 天、00:00–23:59；不存在的夏令时时刻报错，重复时刻采用系统日历默认的首次匹配。
- 本次原生附件测试沿用的合成 PDF 生成仍有已知 CoreGraphics 警告，检查结果通过。

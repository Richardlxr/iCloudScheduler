iCloudScheduler 0.3.0

- 登录时静默启动，点击应用或使用快捷键时再打开输入窗口。通用设置支持隐藏菜单栏图标。
- 支持只有开始时间的安排：保存为不占忙碌时间的 1 分钟日历提醒；未指定提醒提前量时在开始时提醒。这类安排属于系统日历事件。
- 支持用一句自然语言补充或调整日程，并提供日期、时段等快捷选项。AI 修改后仍需确认；手动编辑改用原生日期和时间选择器。
- 优化输入区、日程卡片、AI 补全和设置导航。使用系统颜色与静态原生样式，没有新增依赖或持续动画。
- 保留已完成输入自动清空、未完成草稿恢复、冲突提示和有条件撤销。
- 支持 Apple Silicon 和 Intel，macOS 14 及以上。

0.2.0 及以上可从“设置 → 软件更新”下载安装；0.1.x 需手动安装一次。

权限说明：当前仍沿用 ad-hoc 签名，未进行 Apple Developer ID 签名与公证。更新后系统可能再次请求日历或钥匙串授权；本版尚不能保证保留这些权限。安装包及更新清单继续使用独立的 Sparkle Ed25519 签名验证。

# v0.1.1

修复确认日程页面“已经勾选冲突，仍然无法添加”的问题，简化冲突处理并收紧模型输出规则。

- 冲突窗口底部直接提供“删除 / 仍然添加”。具体假设在卡片内显示，一次点击即可确认并添加；删除仅移除待添加草稿，不删除已有日历事件。
- 确认添加后，全部写入成功便自动收起窗口；失败或结果不确定时保留结果并提示。成功记录可在“近期记录”查看。
- 缺日期、时间无效时显示“补全后添加”，点击直接打开编辑。移除隐藏的核对开关；单项确认窗口更紧凑。
- 模型只输出固定结构 JSON，明确日期、时区、默认时长及提醒规则，不再询问未提供的地点或线上线下；实质缺失的时间仍须补全。
- MiniMax M3 关闭思考、分离 reasoning，并降低采样随机性；保留本地严格校验，不增加自动重试。
- 后台提交无需确认；只有确认全部写入成功才安静结束，冲突或失败仍弹出窗口。
- 提供 Universal DMG：打开后拖入 Applications，同时保留 ZIP 和 SHA256SUMS。

macOS 14+，支持 Apple Silicon 与 Intel。安装包使用 ad-hoc 签名，尚未通过 Apple Developer ID 签名和公证。

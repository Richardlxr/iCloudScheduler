iCloudScheduler 0.6.0

群里第二多的消息不是新安排，而是改期和取消。这一版开始能处理它们。

- **改期**：“组会改到周四下午三点”不再又加一条，而是在日历里找出对应的那条，卡片上显示“原时间 → 新时间”，确认后只改时间和地点，提醒与其他内容保持不变。
- **取消**：“明天的班会取消了”会删掉对应的那一条，近期记录里可以恢复（按取消前的内容重建，提醒等设置需自行核对）。
- **绝不自动执行**：即使开了后台运行或关掉“添加前确认”，改期和取消也一定会打开窗口等你确认。
- **不猜**：只有一条候选才会预先选中，两条以上一定要你点；找不到对应日程会直接说明，改期可以一键改为新增。
- **不碰不该碰的**：有参与者的日程、不可修改日历里的日程只提示到系统日历处理；重复日程只处理被指到的那一次。
- 确认前会重新核对一次目标，日历里如果已经变了就中止，不会改错对象。日历标题始终留在本机，不会发给模型。

共 294 项离线检查通过（核心 149、原生 37、工作流 108）。

支持 Apple Silicon 和 Intel，macOS 14 及以上。0.2.0 及以上可在“设置 → 软件更新”下载安装。

当前仍使用 ad-hoc 签名，未进行 Apple Developer ID 签名与公证；更新后可能需要重新授权日历、提醒事项或钥匙串。更新包与清单继续使用 Sparkle Ed25519 签名验证。

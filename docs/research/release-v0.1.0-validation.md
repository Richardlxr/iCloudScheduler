# v0.1.0 发布核验

日期：2026-09-12。

## 交付范围

- Universal 应用：arm64 + x86_64，二者最低部署版本均为 macOS 14.0。
- `.app` 包体约 6 MB，包含两种架构与多尺寸应用图标；没有第三方 Swift 包、浏览器运行时或本地模型。
- 应用界面只显示版本号 0.1.0；README 包含轻量说明、支付宝/微信收款码和用户指定的商业联系邮箱。
- 后台提交直接尝试添加；只有全部保存并核对成功且无提醒调整时保持安静。冲突、信息不全、失败、不确定结果、部分完成均弹窗。

## 本机检查

- 72 项核心检查通过。
- 25 项原生检查通过，分别执行 arm64 原生和 x86_64 Rosetta 路径。
- 15 项 AppModel 工作流检查通过，分别执行 arm64 和 x86_64 路径；新增前台/后台冲突、后台覆盖前台确认选项、提醒被系统调整的提示检查。
- 共 112 项不同检查；重复执行两种架构不重复计入此数。
- 应用通过 `codesign --verify --strict`；图标的 PNG 源文件和 ICNS 已纳入仓库。

原始输出位于本机 `dist/validation/release-*.log`。模型和日历使用合成实现，不产生付费请求或真实日历写入。

## 仍需区分

x86_64 Rosetta 检查证明 Intel 指令集的离线运行路径通过，不代表 Intel 真机 UI、系统权限或 iCloud 联调已完成。系统最低部署版本为 14，不代表已在所有 macOS 14+ 版本实机测试。

本次包采用 ad-hoc 签名，尚无 Developer ID 签名、公证和 staple。公开 Release 文案保留此事实，不以移除“开发预览”字样替代系统分发验证。

原生合成 PDF 测试仍会输出已知 CoreGraphics 警告；用例检查通过。CLI 工具链存在已知系统库搜索路径警告。真实推理、跨设备同步和系统通知不属于上述离线检查。

iCloudScheduler 0.5.0

这一版的前提变了：你写下的内容就是你认为够用的信息，本机能算出来的一律算出来并写明依据，不再回头让你补一遍。

- **时段**：“明天下午交材料”“周三晚上开会”“下午之前给我”都能直接落到具体时刻（下午 15:00、晚上 20:00 等）。模型只判断说法属于哪一种，日期由本机按提交时间换算。0.4.0 里“明天下午”会被排到明天早上九点，这版修正。
- **截止**：“周五前交”“月底之前缴费”会把时间对齐到截止点，并自动加一条提前提醒——两天以上提前一天，当天提前几小时。
- **重复**：每周例会、课表、每月缴费写成系统日历的重复规则。支持每天、每个工作日、每周（可指定周几）、每两周、每月、每年，带结束日期或次数；复杂重复只添加第一次并说明。
- **待办进提醒事项**：办理、提交、缴费这类待办默认写入“提醒事项”，没做完不会消失，可以勾掉或顺延；会议、上课仍写入日历。需在“设置 → 日历与提醒”授权并选择清单，未授权时继续写入日历，不会丢失；每条草稿也能单独切换目标。
- **农历**：农历八月十五、闰五月十五等用系统农历在本机换算，不再要求改写成公历。
- **多个提醒**：一条日程最多五个提醒，航班、面试这类可以提前一天再提前三小时。
- 缺时间的草稿上提供“尽快 / 今晚 / 明早 / 明天下午 / 本周内”按钮，在本机换算，不额外调用模型。确认卡片显示重复规则、全部提醒和写入目标。

支持 Apple Silicon 和 Intel，macOS 14 及以上。0.2.0 及以上可在“设置 → 软件更新”下载安装。首次把待办写入提醒事项时，macOS 会请求提醒事项权限。

当前仍使用 ad-hoc 签名，未进行 Apple Developer ID 签名与公证；更新后可能需要重新授权日历、提醒事项或钥匙串。更新包与清单继续使用 Sparkle Ed25519 签名验证。

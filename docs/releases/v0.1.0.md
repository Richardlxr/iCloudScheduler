# iCloudScheduler v0.1.0

轻量的原生 macOS 日程助手：快捷键呼出小窗，把文字、图片和 PDF 中的安排转为可编辑日程，并添加到系统日历。

## 功能

- SwiftUI + AppKit 原生界面，无第三方包依赖，不捆绑浏览器内核或本地大模型；包含图标和两种 CPU 架构的 Universal `.app` 约 6 MB。
- 快捷键呼出、拖动位置记忆，可选 Enter / ⌘Enter 提交与提交后后台运行。
- DeepSeek、Kimi、MiniMax、智谱、千问、小米 MiMo 预设及自定义兼容接口；API Key 存入系统钥匙串。
- 支持文字、图片、PDF 选页转图；模型能力测试由用户主动触发。
- 前台可选添加前确认，后台提交直接添加；仅全部核对成功才安静结束。冲突、信息缺失、部分失败或提醒调整均弹窗，不自动重试。
- 自定义提醒与全天提醒时刻；操作记录、写入核对及有条件撤销。

## 下载

下载 `iCloudScheduler-0.1.0-macos-universal.zip`，解压后将 `.app` 拖入“应用程序”目录。使用 `SHA256SUMS` 核对下载文件。

系统要求：**macOS 14+，Apple Silicon（M 系列芯片）或 Intel Mac**。当前安装包为 ad-hoc 签名，**尚未通过 Apple Developer ID 签名与公证**，系统可能阻止首次打开。也可按照 README 从源码构建；同一个 Universal 安装包适用于两种架构。

## 验证与边界

112 项离线检查通过，覆盖日期和时区、配置迁移、原生输入、附件、窗口位置，以及模拟模型和日历的后台流程。模型测试会使用用户账户并可能计费。

离线检查不等同于六家真实模型、iCloud 跨设备同步或系统通知全部通过验收。自动找空档、重复规则、DOCX/ICS、上游原生 PDF 上传、流式响应和自动更新尚未实现。

iCloudScheduler 0.2.0

- 新增完整应用内更新：菜单栏与“设置 → 软件更新”可检查版本、下载、验证签名、安装并重启。
- 自动检查每天一次，发现版本在菜单栏提示，不抢占当前输入；可在设置关闭。
- 更新包和更新清单均使用独立 Ed25519 签名，验证完成后才解包安装。
- 安装重启避开正在生成、写入日程及模型测试；保存可恢复草稿。未完成的编辑、附件或关闭草稿保留时的输入需先处理，防止丢失。
- 删除选中的待添加日程后自动关闭窗口，与添加成功行为一致。
- 同时支持 Intel 和 Apple Silicon，macOS 14 及以上。

0.1.x 尚无更新入口，首次需要下载此 DMG 并安装；之后可在应用内更新。
当前仍为 ad-hoc 签名，未进行 Apple Developer ID 公证。更新后系统可能重新请求日历或钥匙串授权；更新签名不会绕过 macOS 权限。

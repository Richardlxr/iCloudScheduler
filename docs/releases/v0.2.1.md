iCloudScheduler 0.2.1

- 修复添加或删除日程后，再次呼出仍显示上一次内容的问题。当前输入中的日程全部处理完成后，会清空原文、附件和草稿，直接开始新输入。
- 后台添加成功也会结束当前输入；操作记录仍可在“近期记录”主动查看。
- 未选中、尚未处理的日程继续保留。生成失败、写入失败、结果不确定或提醒需要核对时，仍保留内容并提示处理。
- 修复重启后恢复已完成输入的问题，同时清理旧版本留下、已确认全部添加成功的草稿。
- 支持 Apple Silicon 和 Intel，macOS 14 及以上。

0.2.0 可从“设置 → 软件更新”检查、安装并重启；0.1.x 需手动下载安装一次。
当前仍为 ad-hoc 签名，未进行 Apple Developer ID 公证；更新后系统可能重新请求日历或钥匙串授权。

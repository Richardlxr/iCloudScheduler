# v0.2.1 输入清理核验

核验日期：2026-09-12。版本 0.2.1，构建号 4；Sparkle 更新公钥与 0.2.0 保持一致。

## 行为与验证

- 当前输入中的日程全部添加成功或删除后，清空原文、附件、草稿和本次结果，关闭窗口；再次呼出显示空白输入。
- 后台添加成功执行相同清理；近期操作记录继续保存在日志中，可主动查看。
- 未选中、尚未处理的草稿保留；失败、结果不确定及提醒警告仍保留内容并提示。
- 草稿清理在收起窗口前持久化；重启不恢复已完成内容。旧版本遗留且日志已确认全部保存成功的草稿同样清理。
- 76 项核心检查、25 项原生存储/附件检查、50 项流程检查全部通过，共 151 项。50 项流程检查另通过 x86_64 / Rosetta 运行验证；未在 Intel 实机执行。
- 前一轮 GUI 隔离验证已实际提交合成日程并确认添加：再次呼出为空白，主动打开近期记录仍能看到结果。输入未提交文字后按 Esc 收起，再次呼出仍保留文字。删除与重启恢复由离线流程检查验证。
- 本次发布重建 Universal 应用，未更改上一轮已验证的运行逻辑；未调用真实模型、钥匙串中的模型凭证或用户日历。

构建、核心、原生、流程及 Intel 检查日志位于 `dist/validation/release-v0.2.1-*.log`；GUI 证据为 `dist/validation/capture-completion-reopen.png` 和对应文本。

## 范围

此版本保留 Sparkle 2.9.6、独立 Ed25519 更新签名及 DMG 分发流程。完整替换、重启与篡改拦截已在 [v0.2.0 更新核验](release-v0.2.0-validation.md) 中验证；本次重新检查发布包、清单签名和上一版对新版本的发现。未重复验证真实日历写入、跨设备同步或提醒触发。

应用仍为 ad-hoc 签名，未公证。本次发布不替换用户 `/Applications` 中的应用；可通过应用内更新安装。

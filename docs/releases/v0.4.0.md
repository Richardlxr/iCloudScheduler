iCloudScheduler 0.4.0

- 只写了“尽快”“今晚”“本周内”的催办、办理一类待办现在能直接生成提醒：模型只判断时限措辞属于哪一类，具体时刻由本机按提交时间换算成不占忙碌时间的时间点提醒，确认窗口写明换算依据，可随时改。
- 同一条群消息里点名多人时合并成一条日程，人名和学号写进备注，不再拆成几条或反复追问。
- 草稿仍缺时间时，卡片上直接提供“尽快 / 今晚 / 明天 / 本周内”按钮，在本机换算，不再额外调用模型。
- 修复输入法拼音上屏前与提示文字重叠。
- 拖入或粘贴文件现在成为附件，不再把文件路径写进输入框；拖动时显示放置提示。
- 含文字层的 PDF 默认提取所选页面的文字发送，更贴近原文，也不需要先通过图片测试；扫描件仍按页转图，可在附件卡片切换“按文本 / 按图片”。
- 输入卡片、附件卡片与确认卡片的排版调整：焦点描边、附件缩略图、更紧凑的页码设置和更清楚的缺时间提示。

共 225 项离线检查通过（核心 108、原生 33、工作流 84）。

支持 Apple Silicon 和 Intel，macOS 14 及以上。0.2.0 及以上可在“设置 → 软件更新”下载安装。

当前仍使用 ad-hoc 签名，未进行 Apple Developer ID 签名与公证；更新后可能需要重新授权日历或钥匙串。更新包与清单继续使用 Sparkle Ed25519 签名验证。
